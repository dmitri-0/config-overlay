# Улучшения подсветки синтаксиса 1С

## Исправленные проблемы

### 1. Комментарии - убран курсив

**Проблема**: В комментариях часть текста была курсивом (например, "массив сотрудников для проверки"), а часть - обычным текстом ("СправочникСсылка.Cотрудники").

**Решение**: Убрали `italic=True` из настроек комментариев:

```python
# Было:
'comment': ('#6A9955', False, True),  # Зеленые курсивом

# Стало:
'comment': ('#6A9955', False, False), # Зеленые БЕЗ курсива
```

**Результат**: Теперь все комментарии отображаются единообразно - зеленым обычным текстом.

---

### 2. Многострочные строки - автоматическая обработка

**Проблема**: SQL-запросы и другие многострочные тексты в 1С пишутся так:

```bsl
Запрос.Tекст = 
    "ВЫБРАТЬ
    |    Свойства.Ссылка КАК Свойство
    |ПОМЕСТИТЬ BT_Свойство
    |ИЗ
    |    ПланВидовХарактеристик.ДополнительныеРеквизитыИСведения КАК Свойства
    |ГДЕ
    |    Свойства.ИдентификаторДляФормул = """ИдентификаторУчетнойЗаписиАктивДиректори"""";
```

Каждая строка начинается с `"` и заканчивается на `"`, но это **одна целая строка** в коде 1С.

**Решение**: Pygments-лексер `pygments-bsl` **автоматически** распознает эту синтаксическую конструкцию и отмечает весь блок как одну строку.

Никаких дополнительных настроек не требуется - `pygments-bsl` уже знает о специфике 1С.

**Результат**: Все строки SQL-запросов теперь подсвечиваются оранжевым (цвет строк).

---

### 3. Удален Fallback-режим

**Причина**: У вас установлен `pygments-bsl`, поэтому fallback-режим с регулярными выражениями не нужен.

**Изменения**:
1. Удалены методы:
   - `_compile_patterns()`
   - `_highlight_with_regex()`
   - `_is_in_ranges()`

2. Добавлена проверка наличия `pygments-bsl`:

```python
if PYGMENTS_AVAILABLE:
    try:
        self.lexer = get_lexer_by_name('bsl')
    except:
        raise RuntimeError(
            "pygments-bsl не установлен. "
            "Установите: pip install pygments-bsl"
        )
else:
    raise RuntimeError(
        "Pygments не установлен. "
        "Установите: pip install Pygments pygments-bsl"
    )
```

**Результат**: 
- Код стал проще и чище
- Удалено ~150 строк ненужного кода
- Если Pygments нет - выдается четкое сообщение об ошибке

## Что осталось

Теперь `OneCHighlighter` - это **тонкая обертка** над `pygments-bsl`, которая:

1. **Получает токены** от Pygments
2. **Преобразует** их в `QTextCharFormat`
3. **Применяет** форматирование через `setFormat()`

Вся логика разбора синтаксиса 1С лежит в `pygments-bsl`.

## Как проверить

### Комментарии

```bsl
// Возвращает сотрудников из СправочникСсылка.Cотрудники
//
// Параметры:
//  МассивСотрудников - Массив из СправочникСсылка.Сотрудники - массив сотрудников для проверки
```

**Результат**: Весь текст одинакового стиля - зеленый, без курсива.

### Многострочные строки

```bsl
Запрос.Tекст = 
    "ВЫБРАТЬ
    |    Поле1,
    |    Поле2
    |ИЗ
    |    Таблица1
    |ГДЕ
    |    Условие = Истина";
```

**Результат**: Все строки с `"ВЫБРАТЬ` до `Истина"` подсвечены оранжевым.

## Дополнительные возможности pygments-bsl

`pygments-bsl` уже знает о:

- Многострочных строках с `"`
- Датах в формате `'20260209'` и `|` 
- Директивах препроцессора (`#Если`, `#Область`)
- Аннотациях (`&НаКлиенте`, `&НаСервере`)
- Всех ключевых словах и встроенных функциях 1С
- Комментариях `//`

Поэтому все работает автоматически!
